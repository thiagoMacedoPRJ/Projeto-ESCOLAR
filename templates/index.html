O PROJETO BOX ESCOLAR FOI CRIADO EM 2019!

O projeto Box_Escolar tem como proposito recolher eletronicos descartaveis para a reutilização na robótica..

Sobre o projeto

Desde 2019 recolhemos mais de 2000 eletronicos descartaveis para reutilizarmos na robotica!

Não só usamos materiais eletronicos descartaveis na robótica, mas também usamos materiais plásticos como Matéria prima para as impressoras 3D conseguimos produzir filamento a partir de garrafas pets!

Historia do projeto!

  • CAIXA DA REUTILIZAÇÃO

    Criado pela primeira vez em 2019 por um ex-aluno do Darcy Ribeiro, o projeto BOX ESCOLAR consiste na coleta de eletrônicos descatavel para os integrante do grupo separarem esses eletrônicos para uso na robótica, como forma de reaproveitar e sustentar o meio ambiente, E nesta semana do SNCT - Semana Nacional de Tecnologia, Vamos reviver este projeto para trazer a robótica sustentável para ajudar um ambiente poluído desde a Revolução Industrial das décadas de 1820 e 1840.
